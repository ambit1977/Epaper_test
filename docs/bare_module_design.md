# ESP32 ベアモジュール化 詳細設計

ESP32 DevKit ではなく **ESP32-WROOM-32 モジュール単体**を使ったオリジナル基板を起こす。
これにより DevKit に乗っていた USB-UART チップ、AMS1117 LDO、電源 LED を排除し、
Deep Sleep 中の消費電流を **3-5mA → 10-20µA** に削減する。

---

## 1. ベアモジュール化の動機

| 項目 | DevKit | ベアモジュール |
|------|--------|---------------|
| Deep Sleep 電流 | 3〜5 mA | 10〜20 µA |
| USB-UART チップ (CP2102) Iq | 3-5 mA | なし |
| AMS1117 LDO Iq | 5 mA | MCP1700 (1.6µA) に置換 |
| 電源 LED | 2 mA | なし |
| 寸法 | 55 × 28 × 13 mm | 25.5 × 18 × 3 mm + 周辺回路 |
| 価格 | 800〜1500円 | 600〜900円（モジュール単体） |
| 書き込み | USB-C ケーブル直挿し | FTDI アダプタ別途必要 |

ESP32 本体（ESP32-D0WD-V3）の Deep Sleep は約 10µA なので、DevKit を使うと **300〜500倍** の電流を浪費している。

## 3. 回路図（テキスト版）

```
                  USB-C (5V)
                       │
                       ▼
                 ┌──────────┐
                 │  TP4056  │ ── BAT+ ──┐
                 │ + DW01   │           │
                 └──────────┘           ▼
                       │              [Li-Po 3.7V]
                       └── BAT- ──────┘
                                   │
                       ┌───────────┴───────────┐
                       │                       │
                       ▼                       ▼
                 ┌──────────┐          (バッテリー監視)
                 │ MCP1700  │           GPIO34 等で
                 │  -3302E  │           分圧電圧読み取り
                 │  3.3V    │
                 └──────────┘
                       │
                  ┌────┴────┐
                  │  3.3V   │
                  ▼         ▼
                ESP32   E-Paper VCC
              (3V3 pin)
```

### ESP32-WROOM-32 接続

```
        +────[10kΩ]── 3.3V
        │
        EN ────[0.1µF]── GND
        │              [RESET button] ── GND
        │
ESP32   3V3 ─── 3.3V (MCP1700 出力)
WROOM   GND ─── GND
        │
        GPIO0 ──[10kΩ]── 3.3V
        │
        │      [BOOT button] ── GND
        │
        GPIO15 ──[10kΩ]── GND (ブートメッセージ抑制)
        │
        TXD0 (GPIO1) ──→ 書き込みヘッダ TX
        RXD0 (GPIO3) ←── 書き込みヘッダ RX
        │
        +── E-Paper / その他 GPIO
```

### 書き込みヘッダ（6ピン）

```
  ┌─ 1: GND        (FTDI GND)
  ├─ 2: 3V3        (FTDI VCC = 接続しない or 切替)
  ├─ 3: TX (ESP32) (FTDI RX)
  ├─ 4: RX (ESP32) (FTDI TX)
  ├─ 5: GPIO0      (FTDI DTR ※自動リセット用)
  └─ 6: EN         (FTDI RTS ※自動リセット用)
```

⚠️ FTDI からの 3.3V/5V は **絶対に ESP32 の 3V3 ピンに直結しない**。
ESP32 への電源は MCP1700 (リポ駆動) からのみ。FTDI の VCC は接続しないか、
ジャンパで切り替えできるようにする。

## 4. ピン配置（E-Paper との接続）

ベアモジュール化しても **GPIO アサインは現行と同じ**にすると、スケッチ変更ゼロ：

| 信号 | ESP32-WROOM-32 ピン | E-Paper |
|------|---------------------|---------|
| BUSY | GPIO4 (IO4) | PIN 1 (BUSY) |
| RES | GPIO17 (IO17) | PIN 2 (RES) |
| D/C | GPIO16 (IO16) | PIN 3 (D/C) |
| CS | GPIO23 (IO23) | PIN 4 (CS) |
| SCL | GPIO5 (IO5) | PIN 5 (SCL) |
| SDA | GPIO18 (IO18) | PIN 6 (SDA) |
| GND | GND | PIN 7 |
| VCC | 3.3V | PIN 8 |

⚠️ **ストラッピングピン注意**:
- GPIO0, GPIO2, GPIO12, GPIO15 は起動時の状態でブートモードが決まる
- 現状の E-Paper 配線は GPIO0/2/12/15 を使っていないので問題なし

## 5. 自動リセット回路（書き込みを楽にする）

毎回 BOOT/RESET ボタンを押すのが面倒なら、FTDI の DTR/RTS で自動リセット：

```
FTDI DTR ──[0.1µF]──┬── 2N3904 base
                    │
                    └── [10kΩ] ── 3.3V

FTDI RTS ──[0.1µF]──┬── 2N3904 base
                    │
                    └── [10kΩ] ── 3.3V

各トランジスタの collector → GPIO0 / EN
emitter → GND
```

これがあれば arduino-cli や esptool が自動で書き込みモードに入れる。
作るのが面倒ならボタン手動でも十分（書き込み回数も限られるので）。

---

## 6. 書き込み手順

### 自動リセット回路ありの場合

```bash
arduino-cli compile --upload \
  -p /dev/cu.usbserial-XXXX \
  --fqbn esp32:esp32:esp32:UploadSpeed=115200,PartitionScheme=huge_app \
  sketches/05_weather_display_lp
```

DevKit と全く同じコマンドで OK。

### 手動リセット回路の場合

1. BOOT ボタンを押し続ける
2. RESET ボタンを一回押して離す
3. BOOT ボタンを離す
4. ESP32 が bootloader モードに入る
5. PC から書き込みコマンド実行
6. 書き込み完了後、RESET 一回で実行開始

## 7. プリント基板 vs 万能基板

### 万能基板（手はんだ、初心者向け）
- メリット: 安い、すぐ始められる
- デメリット: ESP32-WROOM-32 は表面実装で 38ピン、ピッチ 1.27mm → ピンヘッダ化アダプタが必要
- 必要部材: **ESP32-WROOM-32 ブレークアウトボード** (2.54mm 変換基板) を別途購入

### プリント基板（PCB 業者発注）
- メリット: きれい、量産可能、サイズ最適化
- デメリット: 初期工数（KiCad で起こす）、納期1-2週間
- 業者: JLCPCB, PCBWay 等、5枚 $5 程度

### 推奨: ESP32-WROOM-32 ブレークアウトボード + 小型万能基板
- ブレークアウトボード（秋月にあり）に WROOM をはんだ付け
- 万能基板に LDO、TP4056、抵抗、コンデンサを配置
- ジャンパワイヤで結線

## 8. 配線リスト（万能基板での実装例）

```
電源系:
[USB-C コネクタ]
  └─ 5V → TP4056 IN+
  └─ GND → TP4056 IN-

[TP4056]
  ├─ B+ → [Li-Po +]
  ├─ B- → [Li-Po -]
  ├─ OUT+ → MCP1700 VIN
  └─ OUT- → GND（全体GND）

[MCP1700-3302E (TO-92)]
  ├─ pin1 VIN → TP4056 OUT+
  ├─ pin2 GND → GND
  └─ pin3 VOUT → ESP32 3V3, E-Paper VCC
  + 入力に 1µF、出力に 10µF

[ESP32-WROOM-32 ブレークアウト基板]
  ├─ 3V3 → MCP1700 VOUT
  ├─ GND → GND
  ├─ EN → 10kΩ → 3V3、0.1µF → GND、ボタン → GND
  ├─ GPIO0 → 10kΩ → 3V3、ボタン → GND
  ├─ GPIO15 → 10kΩ → GND
  ├─ GPIO1 (TX) → 書き込みヘッダ pin3
  ├─ GPIO3 (RX) → 書き込みヘッダ pin4
  └─ 各GPIO → E-Paper / その他

[書き込みヘッダ (6 pin)]
  pin1: GND
  pin2: 3V3 (FTDI VCC は接続しない)
  pin3: ESP32 TX → FTDI RX
  pin4: ESP32 RX → FTDI TX
  pin5: GPIO0 → FTDI DTR (自動リセット使う場合)
  pin6: EN → FTDI RTS (同上)
```

## 12. リスク管理

| リスク | 対策 |
|-------|------|
| TP4056 と DW01 を混同して保護回路欠落 | 「保護回路 (Protection) 付き」と明記のあるモジュールを選ぶ |
| MCP1700 が逆挿し | TO-92 ピン配置を確認、逆挿しすると即死 |
| ESP32 への 5V 直接印加 | 配線時に必ずテスター電圧確認 |
| リポバッテリー過放電 | DW01 の過放電カット (2.5V) で守られているはず、念のため動作時の電圧監視を入れる |
| 書き込み時の FTDI と LDO の VCC 競合 | FTDI VCC は接続しない（書き込み時もリポから給電） |
| ストラッピングピン誤接続 | GPIO0, GPIO2, GPIO12, GPIO15 の状態を回路図で再確認 |
