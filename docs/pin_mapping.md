# 配線図とトラブルシュート

## 動作確認済みの物理配線

このリポジトリのコードは以下の配線で動作確認している：

```
ESP32 DevKit V1                 WeAct 2.9" E-Paper
                                 (JST 8pin side)
┌──────────────┐               ┌─────────────────┐
│              │               │                 │
│ 3.3V ────────┼──── 赤 ───────┤ PIN 8 VCC       │
│ GND  ────────┼──── 黒 ───────┤ PIN 7 GND       │
│ GPIO4  ──────┼──── 紫 ───────┤ PIN 1 BUSY      │
│ GPIO17 ──────┼──── オレンジ ─┤ PIN 2 RES       │
│ GPIO16 ──────┼──── 白 ───────┤ PIN 3 D/C       │
│ GPIO23 ──────┼──── 青 ───────┤ PIN 4 CS        │
│ GPIO5  ──────┼──── 緑 ───────┤ PIN 5 SCL       │
│ GPIO18 ──────┼──── 黄 ───────┤ PIN 6 SDA       │
│              │               │                 │
└──────────────┘               └─────────────────┘
```

## 信号別一覧

| 信号 | ESP32 GPIO | ケーブル色 | E-Paper JST PIN | 役割 |
|------|-----------|----------|-----------------|------|
| BUSY | GPIO4 | 紫 | 1 | E-Paper → ESP32 ビジー状態信号 |
| RES | GPIO17 | オレンジ | 2 | E-Paper リセット |
| D/C | GPIO16 | 白 | 3 | コマンド/データ切替 |
| CS | GPIO23 | 青 | 4 | SPI チップセレクト |
| SCL | GPIO5 | 緑 | 5 | SPI クロック |
| SDA | GPIO18 | 黄 | 6 | SPI データ (MOSI) |
| GND | GND | 黒 | 7 | グラウンド |
| VCC | 3.3V | 赤 | 8 | 電源 (3.3V) |

## 重要：ケーブル色の警告

**WeAct 2.9" E-Paper の付属 JST ケーブルは、基板シルク表記とケーブル色配置が一致していない。**

例：
- 基板に「BUSY」と書かれているピンに紫色のケーブルが繋がっている **とは限らない**
- 「黄色は SCL」のような色の慣習は **このモジュールでは成立しない**

これは中華製安価モジュールでよくある初期不良ではなく仕様。
組み立て時に色順がランダム配線されることがある。

## 配線が正しいか確認する方法

### 方法 1: GPIO ループバックテスト

E-Paper を一旦外して、ESP32 の GPIO 同士をジャンパで直結する。
`sketches/diagnostic/loopback_test.ino` を使う。

### 方法 2: 信号制御テスト + マルチメーター

E-Paper を接続したまま、ESP32 から各信号を HIGH/LOW に切り替える。
JST コネクタ側のピンにマルチメーターを当てて、期待通りの電圧が出ているか測定。
`sketches/diagnostic/signal_check.ino` がインタラクティブにこれをサポートする。

### 方法 3: コントローラ自動判定

複数の GxEPD2 ドライバクラスを順番に試して、表示が出るものを探す。
`sketches/diagnostic/epaper_autotest.ino`

## ハードウェアジャンパ（モジュール裏面）

WeAct 2.9" の裏面には以下のジャンパパッドがある：

- **SB3**: VCC 3.3V Only モード
- **SB4 + SB5**: VCC 3.3-5V モード
- **4-Lines SPI / 3-Lines SPI**: SPI 線数切替

このリポジトリのコードは **4-Lines SPI** 前提。
裏面の「4-Lines SPI」側のパッドがハンダブリッジされていることを目視確認すること。
