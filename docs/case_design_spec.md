## 2. 電源構成

```
[単4×3] ─→ [+4.5V] ─→ ESP32 VIN ピン
                       (内蔵 LDO → 3.3V)
[GND] ─→ ESP32 GND ピン
```

### 設計上の注意

- ESP32 DevKit の VIN は通常 5-12V 想定だが、4.5V でも内部 LDO (AMS1117-3.3) で動作する
- アルカリ電池が消耗し 3.6V を下回ると LDO がドロップアウトして不安定 → 早めに交換
- 想定稼働時間（10分間隔更新、Deep Sleep 中 ~50µA、起動時 100mA × 15秒）：
  - アルカリ単4（1200mAh）: 約 12 日
  - エネループ単4（750mAh）: 約 7 日
- 書き込み・USB 給電時の電池との競合を避けるため、**電池ライン VIN 間にショットキーダイオード**（1N5817 等）を直列で挿入する
  - USB 給電時: VIN に直接 5V が供給され、ダイオード逆方向で電池からの電流はゼロ
  - 電池駆動時: ダイオードを順方向に通って 4.5V - 0.3V = 約 4.2V が VIN に供給
- 電源スイッチは設けない（USB を抜けば停止、電池運用は電池ホルダーから抜く）

## 3. 外形・全体寸法

### 採用するスタイル
**卓上スタンド型（フォトフレーム風）、15° 傾斜、USB-C を背面下から引き出せる構造**

- 表面に E-Paper を表示
- 背面に ESP32 + 電池 + 配線を収納
- 底面にスタンド脚（一体型）
- 背面下から USB-C ケーブルを引き出せる切り欠き

### 概算外形寸法

| 部位 | 寸法 (mm) | 補足 |
|------|----------|------|
| 全体（W × H × D） | **130 × 105 × 30** | 突出物（脚・コネクタ）除く |
| 内部高さ（背面厚） | 22 | パネル4mm + 電池13mm + マージン5mm |
| 前面マージン（表示エリア周り） | 上下左右 7mm | パネルガラスより一回り大きく |
| スタンド脚の張り出し | 後方 +25mm | 15° 確保のため |

## 4. 内部レイアウト（背面ふた側）

```
背面 (内側から見た図)
┌──────────────────────────────────────────────┐
│                                              │
│   ┌──────────────┐    ┌────────────────┐    │
│   │   電池ホルダー │    │   ESP32 DevKit │    │
│   │  単4 × 3      │    │                │    │
│   │   50 × 36     │    │   55 × 28      │    │
│   └──────────────┘    └────────────────┘    │
│         ↑                    ↑               │
│         スイッチ              USB-C 開口      │
│                                              │
│        ◯ジャンパワイヤループ収納スペース      │
│                                              │
└──────────────────────────────────────────────┘
     ↑ ヒンジ/スライド/ねじ（下記参照）
```

### 部品配置

- **電池ホルダー（左）**: 交換アクセスを優先して左側
- **ESP32（右）**: USB-C 端子を背面下に向けて、書き込み時にケーブル接続可能に
- **配線スペース**: 中央下にゆるく8本を巻いて収納
- **ダイオード**: 電池ホルダーの+リードと ESP32 VIN の間に空中配線（1N5817 直径4mm、長さ5mm）

### 固定方法

- ESP32: M2.5 × 5mm ねじ + 真鍮インサート（または直接タッピング）4本
- 電池ホルダー: 両面テープ or プリント時の溝に圧入
- E-Paper: M2 × 5mm ねじ 4本

## 6. 開閉方式

**採用案：M2.5 × 4本のねじ留め（角四隅）+ 真鍮インサート埋め込み**

理由：
- 製作工数と確実性のバランスが良い
- 何度開閉しても緩まない（インサート）
- 電池交換は数週間に一度なので、ねじ留めでも実用上 OK

ねじ位置：
- ケース四隅、E-Paperの取付穴を避けたところ

> 候補B（スナップフィット）も可能だが、PLA で経年劣化しやすいので推奨しない。

## 8. 設計上の重要な「現物確認」事項

CAD 起こし前に必ず確認：

1. 🪛 **WeAct 4.2" 基板の四隅取付穴の正確な間隔（中心間距離）**
2. 🪛 **ESP32 DevKit V1 の取付穴ピッチと径**
3. 📏 **単4電池ホルダーの実寸とリード線出口位置**
4. 🔌 **USB-C コネクタの基板上での突出長と位置**
5. 🪞 **E-Paper ガラス面の基板からの突出量**（前面板の凹み深さに影響）
