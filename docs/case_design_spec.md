## 2. 電源構成

```
USB-C (5V) ──→ TP4056 充電基板 ──┬── [Li-Po 3.7V (1000mAh)]
                                  │
                                  └─→ MCP1700 LDO ──→ 3.3V
                                                       │
                                                       ├─→ ESP32-WROOM-32 (3V3)
                                                       └─→ E-Paper VCC
```

### 設計上の注意

- ESP32 はそもそも 3.3V 駆動。リポ 1セル (3.0-4.2V) → MCP1700 LDO で **1段降圧のみ**
- MCP1700 の Iq = 1.6µA → Deep Sleep 中の損失極小
- TP4056 が **充電 + 過充電/過放電保護** を担当（保護回路付きモジュールを選定）
- USB-C 給電中もリポは無理せず充電できる
- 想定稼働時間（10分間隔更新、Deep Sleep < 20µA 達成時）：
  - リポ 1000mAh: **約 1.5 ヶ月**
  - 充電後の運用可能日数として大きな改善
- 電源スイッチは設けない（USB の抜き差し or リポの JST コネクタ抜きで対応）

## 3. 外形・全体寸法

### 採用するスタイル
**卓上スタンド型（フォトフレーム風）、15° 傾斜、USB-C を背面下から引き出せる構造**

- 表面に E-Paper を表示
- 背面に ESP32 + 電池 + 配線を収納
- 底面にスタンド脚（一体型）
- 背面下から USB-C ケーブルを引き出せる切り欠き

### 概算外形寸法（リポ角型版）

| 部位 | 寸法 (mm) | 補足 |
|------|----------|------|
| 全体（W × H × D） | **130 × 95 × 18** | 突出物（脚・コネクタ）除く。薄型化 |
| 内部高さ（背面厚） | 12 | パネル4mm + 万能基板6mm + マージン2mm |
| 前面マージン（表示エリア周り） | 上下左右 7mm | パネルガラスより一回り大きく |
| スタンド脚の張り出し | 後方 +20mm | 15° 確保のため |

## NFC 連携（外付け NTAG ステッカー）

詳細は [smart_business_card_design.md](smart_business_card_design.md) と
[business_card_site_design.md](business_card_site_design.md) を参照。

電子ペーパー名刺デバイス自体には NFC IC を搭載しない。NFC は別途用意した
NTAG213/215 ステッカー（25mm 円形、1枚 50-100円）に
**固定 URL `https://ambit.go2020.tokyo/card/` を 1回だけ書き込む**運用。

ケースの背面右下などに **凹みを設けて NTAG ステッカーを貼る** だけでよい：
- 凹み: 30 × 30mm、深さ 1mm（ステッカー貼付用）
- E-Paper パネルの金属層から離す（距離 3mm 以上）
- フェライトシート（薄手 30 × 30 × 0.3mm）を挟むと読み取り距離が安定

ハードウェア配線は不要なので、ケース内に追加配置するものはない。
動的な状況発信はサーバの `now.json` 経由で行う。

```
背面 (内側から見た図、リポ角型版)
┌──────────────────────────────────────────────┐
│                                              │
│   ┌──────────────────────────────────┐       │
│   │      ESP32 ベアモジュール基板    │       │
│   │  WROOM-32 + LDO + TP4056         │       │
│   │      60 × 40 mm                  │       │
│   └──────────────────────────────────┘       │
│                  ↑                            │
│                  USB-C 開口（背面下）         │
│                                              │
│   ┌────────────────────────┐                  │
│   │   Li-Po 1000mAh        │                  │
│   │   50 × 25 × 6 mm       │                  │
│   └────────────────────────┘                  │
│         JST 2.0mm でモジュールに接続           │
│                                              │
│        ◯ジャンパワイヤループ収納スペース      │
│                                              │
└──────────────────────────────────────────────┘
     ↑ ねじ留め（下記参照）
```

### 部品配置

- **ESP32 ベアモジュール基板（上）**: USB-C ポートを背面下に向ける
- **リポバッテリー（下）**: 両面テープで底面に貼り付け、JST コネクタで脱着可能に
- **配線スペース**: 中央にゆるく8本を巻いて収納
- **書き込み用ヘッダ**: ケース内部、開閉時のみアクセス（普段は見えない）

### 固定方法

- ESP32 ベアモジュール基板: M2.5 × 5mm ねじ + 真鍮インサート 4本
- リポバッテリー: 両面テープ（リポは直接ねじ留めしない、絶縁テープで養生）
- E-Paper: M2 × 5mm ねじ 4本

## 6. 開閉方式

**採用案：M2.5 × 4本のねじ留め（角四隅）+ 真鍮インサート埋め込み**

理由：
- 製作工数と確実性のバランスが良い
- 何度開閉しても緩まない（インサート）
- 電池交換は数週間に一度なので、ねじ留めでも実用上 OK

ねじ位置：
- ケース四隅、E-Paperの取付穴を避けたところ

> 候補B（スナップフィット）も可能だが、PLA で経年劣化しやすいので推奨しない。

## 8. 設計上の重要な「現物確認」事項

CAD 起こし前に必ず確認：

1. 🪛 **WeAct 4.2" 基板の四隅取付穴の正確な間隔（中心間距離）**
2. 🪛 **ESP32 DevKit V1 の取付穴ピッチと径**
3. 📏 **単4電池ホルダーの実寸とリード線出口位置**
4. 🔌 **USB-C コネクタの基板上での突出長と位置**
5. 🪞 **E-Paper ガラス面の基板からの突出量**（前面板の凹み深さに影響）
